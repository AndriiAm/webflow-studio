# Multi-page website for Webflow Studio
It's a responsive multi-page website (1920px to 360px) developed for a Webflow studio, based on this layout:
[Design Layout](https://www.figma.com/design/0Mt2UQG6AuXtRhZ3eeGmql/Untitled?node-id=0-1&node-type=CANVAS&t=WNmPPj00UOuKXUqa-0)

**Stack:**  
HTML, CSS (SCSS), JavaScript, Swiper JS, Gulp.

**Live demo:**  
[Webflow Studio](https://andriiam.github.io/webflow-studio/)

## What I Learnt

- **Multi-page Website development:** During the development of this project, I learnt how to build multi-page websites and effectively reuse code blocks across different pages using the BEM methodology, avoiding unnecessary copy-pasting.
